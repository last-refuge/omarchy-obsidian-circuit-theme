# Attribution

## Omarchy

The color palette in `colors.toml` is copied from the Omarchy **Starship** theme. Obsidian Circuit retains its semantic and terminal colors, including the `#ff9f0a` accent. The theme's own additions are the shell surface overrides, the wallpaper collection, documentation, and an optional dock appearance patch.

Source: https://github.com/omacom/omarchy/tree/quattro/themes/starship

The dock patch is based on `shell/plugins/dock/DockWindow.qml` from Omarchy 4.5.0-rc3. It modifies appearance without changing the dock's application model, activation commands, or pinning behavior.

Source: https://github.com/omacom/omarchy/blob/v4.5.0-rc3/shell/plugins/dock/DockWindow.qml

Omarchy's copyright and permission notice are preserved in the root `LICENSE`.

## Artwork

All four wallpapers were generated for this project with OpenAI's built-in image generation tool. They are AI-generated artwork, rather than photographs or manually painted illustrations. Their original files are included without an upscaling claim. Exact prompts are in `docs/artwork/`.

The source Starship theme's space-launch wallpapers are not redistributed here. The public preview is a new capture of an actual Omarchy session containing only theme demonstration content.
