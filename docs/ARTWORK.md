# Artwork

All four wallpapers use an obsidian, graphite, and warm-orange palette. They were generated using the built-in `image_gen` tool with an opaque background. These are their native generated PNGs; they have not been upscaled to a claimed 4K or 5K resolution.

| [Signal Strata](../backgrounds/4-signal-strata.png) | 1672 × 941 | [Prompt](artwork/signal-strata.txt) |

The wide compositions allow normal desktop fill/cropping. Artwork remains separate from the desktop preview: `preview.png` is a real session screenshot, and `docs/gallery/obsidian-circuit.webp` is its reduced gallery version. README thumbnails are presentation copies; use the PNGs under `backgrounds/` for wallpaper.
